# Changelog

## 0.1.0 — 2026-10-28

Первый публичный релиз.

- BitTorrent-движок на `anacrolix/torrent`: magnet, `.torrent`, DHT, PEX,
  трекеры, MSE, uTP/TCP.
- Локальная веб-панель на HTML/CSS/JS, вшитая в exe через `go:embed`.
- Тёмная и светлая темы, поиск, фильтры, drag & drop, детали раздачи.
- Пауза, продолжение, проверка файлов, удаление с данными и без.
- Лимиты скорости, смена папки загрузок и портов на лету.
- Сохранение прогресса без перехеширования (bolt-база завершённых кусков).
- Один экземпляр: повторный запуск открывает работающую панель.
- Один статический `.exe` без Qt и установщика; сборки x64 и ARM64.
- Локальный JSON API с защитой от CSRF.
- Интеграционный тест «сидер → личер» по настоящему протоколу.
